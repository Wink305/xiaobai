# 非技术领域的硬信息清单

> **⚠️ 本清单以中国大陆规则为准。** 里面的营业执照、食品经营许可证、ICP 备案、微信小店类目规则都是中国大陆的。
>
> **用户不在中国大陆时，不要套用本清单。** 各国的经营许可、税务义务、食品法规完全不同——把《食品经营许可证》讲给一个美国烘焙师听，是给出错误建议，比不给建议更糟。
>
> 正确做法：先确认用户在哪个国家/地区，再按当地规则回答。**不知道就问**，这本身就是一条 A 类硬信息。
>
> 想找英文辖区时，套用同样的判据（"缺了会让用户白跑、被拒、违规或事后吃亏"）自行推导，本清单只提供中国大陆的落地例子。

**清单本身的用法**：不是要背下来，是提醒你去想这一类。**平台规则年年变**，拿不准就标明"具体以你那边的规则为准"。

下面按领域列常见项。**不是清单要全，是提醒你去想这一类。** 平台规则年年变，拿不准就标明"具体以你那边的规则为准"。

---

## 开店 / 电商 / 经营主体

- **营业执照** — 线下店网店都要，写着店名和经营者
- **个体工商户 vs 公司** — 个人开店够用，责任个人担；公司适合有合伙人
- **食品经营许可证** — 卖吃的要，蛋糕/面包/熟食/饮品都算
- **行业许可** — 特定行业才能做：医美、教培、成品油、酒类、烟草
- **平台准入** — 平台愿意让你开店的前置条件，各家不同
- **类目选错** — 有些大类选定后不可改，改要重新审核
- **品牌授权** — 卖别人的牌子要授权证明，进货单和付款记录留好
- **收款账户户名** — 必须和执照经营者一致，否则货款提不出来
- **保证金与手续费** — 平台按类目收，各品类金额不同，别编数字
- **无证经营** — 该办的证没办就开张，可能被处罚停业

## 合同 / 法务

- **主体资格** — 签约方有没有这个资质，比如公司是否存续
- **授权代表** — 签字的人有没有权限
- **生效条件** — 什么情况下这份合同才成立（常见：双方签字 + 盖章 + 付款）
- **付款节奏** — 预付 / 尾款 / 分期，各自的风险不一样
- **违约责任** — 对方违约你能拿到什么，通常比"赔偿损失"更具体
- **不可抗力** — 哪些情况不算任何一方的错
- **争议解决** — 出问题去哪解决：仲裁还是法院，这决定了你能不能异地维权
- **排他条款** — 签了就不能跟别人做同类合作，这类最容易漏
- **知识产权归属** — 做出来的东西归谁
- **竞业限制** — 离职后能不能做同行，范围和期限
- **保密条款** — 签了之后你能说什么、不能说什么

## 财税

- **发票** — 有没有票、票种对不对，能不能报销
- **税率和征收方式** — 增值税、所得税，不同主体差别很大
- **核定征收 vs 查账征收** — 记账要求完全不同
- **社保公积金** — 雇员必须交，不交是违法，不是"可选项"
- **个体户的分期免税政策** — 有额度限制，不是永久免税
- **成本票** — 成本要凭证才能在税前扣除
- **账期** — 大公司压货款几个月，小公司要求现结，现金流差别很大

## 医疗 / 健康

- **资质** — 机构有没有执业许可，医生有没有执业医师证
- **适应症 / 禁忌症** — 什么情况能做、绝对不能做
- **知情同意** — 有书面告知和签字
- **术前评估** — 有基础病的风险要单独评估
- **恢复期** — 多久能工作，多久复查
- **费用构成** - 术前检查、手术、耗材、复诊是否另计

**这一节的红线**：涉及用药剂量、诊断结论、要不要手术，一律不给判断。改成"这个得问医生"，并告诉用户该问医生哪几个问题。这不是保守，是把话说准。

但**不给结论 ≠ 不给东西**。以下永远要给：立刻就医的危险信号清单、该问医生的问题、打电话前要准备的信息、怎么跟医生描述症状。用户拿着这些才用得上帮助。

## 儿科与家庭急症（非手术，最常被问）

| 术语 | 白话说法 |
|---|---|
| 发热 | 体温高于正常。多少度算要紧因年龄和来源而不同，别套别人的标准 |
| 退烧药 | 降低体温的药。儿童用哪一种、吃多少，按**体重**和**药盒上的规格**算，不按年龄 |
| 规格（浓度） | 同样叫"布洛芬"，不同瓶子的每毫升含量不同——剂量必须按瓶子上的数字算，不是按药名 |
| 用药间隔 | 距上一次吃药过了多久。没到间隔就吃会过量 |
| 脱水 | 身体缺水。尿少、哭没眼泪、嘴干是信号，孩子比大人危险得快 |
| 精神状态 | 比体温更重要。烧到多少度不一定有事，**叫不醒、软塌、反应和平时不一样**才是危险信号 |
| 皮疹不褪色 | 按压不褪色的红点，可能是严重感染信号，要立刻就医 |
| 惊厥 | 抽搐发作，需要立刻处理 |
| 呼吸费力 | 喘、胸口凹陷、肋间凹陷——要去急诊的信号 |
| 持续高热不退 | 超过某个时长仍不退，要重新评估病因 |
| 就医门槛 | 什么情况必须去医院、什么情况可以先观察。**各国、各医院标准不同** |

> **危险信号清单要全，宁可长。** 漏掉第 6 条的代价远大于列表长了一点。
>
> **用户所在国家/地区不明时先问。** 儿童发热就医门槛、退烧药说明书、急诊分诊标准各国差别很大——中国的 38.5℃ 就医建议不能直接套给英美用户。

## 教育 / 培训

- **办学许可** - 学科类和非学科类要求不同
- **退费规则** - 这是最容易起纠纷的地方，提前问清楚
- **师资资质** - 承诺的名师有没有相应证书
- **合同周期** - 常见"一次性交两年，中途不退"

## 房产 / 租赁

- **产权人** - 你签的对象是不是产权人，有没有授权
- **用途** - 住宅能不能办公、能不能注册
- **租赁备案** - 办理营业执照可能需要
- **押金退还条件** - 什么情况下不退，写清楚
- **提前解约** - 双方各付多少违约

## 通用：任何领域都要问的

- **这一步要花多少钱** - 写不准就标明"我不确定，去问谁"
- **要等多久** - 官方说法和实际经常不一样
- **谁来做** - 用户自己做还是要找专业的人
- **做错了能撤回吗** - 不可逆操作必须显式警告
- **有没有时限** - 错过就失效的（证照年检、报名截止、优惠截止）
- **怎么判断做成了** - 可验证的标志，不是"感觉可以了"
