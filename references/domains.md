# 非技术领域的硬信息清单

「小白」不只是不懂技术。懂技术但不懂法务、财税、医疗的人，吃的是同一套规则，但硬信息完全不同。

**通用判据：这个领域里，缺了哪一条会让用户白跑、被拒、违规或事后吃亏？** 找到它，标成 A 类。

下面按领域列常见项。**不是清单要全，是提醒你去想这一类。** 平台规则年年变，拿不准就标明"具体以你那边的规则为准"。

---

## 开店 / 电商 / 经营主体

- **营业执照** — 线下店网店都要，写着店名和经营者
- **个体工商户 vs 公司** — 个人开店够用，责任个人担；公司适合有合伙人
- **食品经营许可证** — 卖吃的要，蛋糕/面包/熟食/饮品都算
- **行业许可** — 特定行业才能做：医美、教培、成品油、酒类、烟草
- **平台准入** — 平台愿意让你开店的前置条件，各家不同
- **类目选错** — 有些大类选定后不可改，改要重新审核
- **品牌授权** — 卖别人的牌子要授权证明，进货单和付款记录留好
- **收款账户户名** — 必须和执照经营者一致，否则货款提不出来
- **保证金与手续费** — 平台按类目收，各品类金额不同，别编数字
- **无证经营** — 该办的证没办就开张，可能被处罚停业

## 合同 / 法务

- **主体资格** — 签约方有没有这个资质，比如公司是否存续
- **授权代表** — 签字的人有没有权限
- **生效条件** — 什么情况下这份合同才成立（常见：双方签字 + 盖章 + 付款）
- **付款节奏** — 预付 / 尾款 / 分期，各自的风险不一样
- **违约责任** — 对方违约你能拿到什么，通常比"赔偿损失"更具体
- **不可抗力** — 哪些情况不算任何一方的错
- **争议解决** — 出问题去哪解决：仲裁还是法院，这决定了你能不能异地维权
- **排他条款** — 签了就不能跟别人做同类合作，这类最容易漏
- **知识产权归属** — 做出来的东西归谁
- **竞业限制** — 离职后能不能做同行，范围和期限
- **保密条款** — 签了之后你能说什么、不能说什么

## 财税

- **发票** — 有没有票、票种对不对，能不能报销
- **税率和征收方式** — 增值税、所得税，不同主体差别很大
- **核定征收 vs 查账征收** — 记账要求完全不同
- **社保公积金** — 雇员必须交，不交是违法，不是"可选项"
- **个体户的分期免税政策** — 有额度限制，不是永久免税
- **成本票** — 成本要凭证才能在税前扣除
- **账期** — 大公司压货款几个月，小公司要求现结，现金流差别很大

## 医疗 / 健康

- **资质** — 机构有没有执业许可，医生有没有执业医师证
- **适应症 / 禁忌症** — 什么情况能做、绝对不能做
- **知情同意** — 有书面告知和签字
- **术前评估** — 有基础病的风险要单独评估
- **恢复期** — 多久能工作，多久复查
- **费用构成** - 术前检查、手术、耗材、复诊是否另计

## 教育 / 培训

- **办学许可** - 学科类和非学科类要求不同
- **退费规则** - 这是最容易起纠纷的地方，提前问清楚
- **师资资质** - 承诺的名师有没有相应证书
- **合同周期** - 常见"一次性交两年，中途不退"

## 房产 / 租赁

- **产权人** - 你签的对象是不是产权人，有没有授权
- **用途** - 住宅能不能办公、能不能注册
- **租赁备案** - 办理营业执照可能需要
- **押金退还条件** - 什么情况下不退，写清楚
- **提前解约** - 双方各付多少违约

## 通用：任何领域都要问的

- **这一步要花多少钱** - 写不准就标明"我不确定，去问谁"
- **要等多久** - 官方说法和实际经常不一样
- **谁来做** - 用户自己做还是要找专业的人
- **做错了能撤回吗** - 不可逆操作必须显式警告
- **有没有时限** - 错过就失效的（证照年检、报名截止、优惠截止）
- **怎么判断做成了** - 可验证的标志，不是"感觉可以了"
